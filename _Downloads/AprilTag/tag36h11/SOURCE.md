# 区域标记图：AprilTag tag36h11

## 这是什么、为什么需要
AprilTag 是机器人常用的二维视觉标记（类似简化二维码）。相机识别后，可以算出标记相对相机的位置和朝向。
本项目用它做 SOP 中的“区域标记识别 t(2,2)”“标记确认、对接停车 t(2,1)”“基准注册 t(3,2)”：每个工位旁立一块标记板，AGV 识别后完成精确停靠与坐标注册。
仿真中不运行真正的识别算法，标记板主要提供**真实的外观**，再按视场判定是否“可见”。

## 文件
`tag36_11_00000.png` ～ `tag36_11_00011.png`，共 12 张，对应 ID 0～11。每张只有 **10 × 10 像素**（每个像素就是一个黑白格，含 1 格白边），这是正常的。

## ID 分配（v1 默认，写入 CFG_Inspection）
| ID | 用途 |
|---|---|
| 0、1 | 区域 1（机身左侧）工位 1、工位 2 的停靠标记 |
| 2、3 | 区域 2（机身右侧）工位 1、工位 2 的停靠标记 |
| 4～7 | 4 个工位的检测区基准标记（基准注册 / 每 10 颗复测） |
| 8 | 充电位对接标记 |
| 9～11 | 备用 |

## 导入说明（给 M2）
- 复制到 `Assets/ThirdParty/AprilTag/tag36h11/`。
- 导入设置：Filter Mode = **Point**，关闭 Mip Maps，Compression = None，Wrap = Clamp。否则会被模糊成灰色方块。
- 标记板外圈需再加一圈白边，保证识别所需的空白区；边长建议 0.20 m（工位标记）、0.10 m（基准标记）。
